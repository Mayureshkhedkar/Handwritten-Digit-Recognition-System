***Handwritten Digit Recognition using CNN***

A deep learning-based web application that recognizes handwritten digits (0–9) using a Convolutional Neural Network (CNN).
The model is trained on the MNIST dataset and deployed through a Flask web application where users can upload handwritten digit images and receive instant predictions.

**Project Description**

This project implements a CNN-based handwritten digit recognition system using TensorFlow and Keras.
The trained model is integrated with a Flask backend and a responsive HTML/CSS frontend to provide real-time digit prediction through a web interface.

The system performs:
1.Image preprocessing.
2.Digit classification using CNN.
3.Real-time prediction display.
The project demonstrates the practical deployment of deep learning models in web applications.
